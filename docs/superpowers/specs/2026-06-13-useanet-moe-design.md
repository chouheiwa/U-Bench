# USEANet-MoE 设计稿

*日期:2026-06-13 · 状态:已脑暴定稿,待写实现计划 · 关联记忆:`useanet-moe-paper`、`useanet-integration`*

---

## 0. 一句话

在已接入 U-Bench 的 USEANet 基础上,把其现有的弱 dense soft-MoE(`MultiBranchFeatureProcessor`)升级为**超声物理退化类型的稀疏 MoE**,并配一个**可微超声物理退化模拟器**作为第二支柱(增强 + 路由监督 + 可控实验),目标是一篇以"超声物理 MoE 分割"为干净核心、以"跨模态可迁移"为加分的论文。

## 1. 背景与动机

- USEANet 现有的 `models/Hybrid/USEANet/usea_core.py:MultiBranchFeatureProcessor`(noise/edge/contrast 三分支 + 图像级 softmax)本质上已是一个**弱的 dense soft-MoE**:三个专家全算、图像级软加权、无 top-k、无负载均衡、无退化监督。
- 文献调研(`output/USEANet_MoE_research.md` + 2026-06-13 二次重扫)确认:**超声分割 + MoE 是空白**(唯一的 MoE+超声是 SEMC,做分类);**通用退化 MoE / 多模态医学 MoE 已饱和**,故走"超声物理"专门化而非通用路线。

## 2. Novelty 定位(两支柱)

> **① 超声物理退化类型 MoE 分割(核心,干净)**
> 专家按超声成像物理(斑点、边缘、**声影**、**后方回声增强**)显式定义,由读取 label-free 退化线索(局部方差/梯度/频带能量)的退化感知路由器做 top-2 空间自适应混合。
>
> **② 可微超声物理退化模拟器闭环(novelty 增益)**
> 同一模拟器同时充当:数据增强、路由器的物理 ground-truth 监督、可控退化实验。把 image-formation 物理与分割 MoE 闭环——文献未占。

**跨模态迁移**(U-Bench 其他模态)作为加分次要结果。机制天然成立:非超声图上声影/后方增强的退化代理图 ≈ 0,路由器自动下调这两个专家,边缘/对比/去噪专家接管。

### 2.1 撞车切割(必须在 related work 处理)

| 对手 | 它做什么 | 我们怎么切 |
|---|---|---|
| SEMC (2511.12559) | MoE+超声,但**分类** | 任务不同(分割) |
| M4oE / MoME / SegMoTE / MedMoE | MoE+多模态医学分割,**模态专家** | 我们是**退化类型专家**(模态无关),且只把跨模态当加分 |
| MoR / DDER / M2Restore / MiM-DiT | 退化类型专家+退化路由,但**图像复原** | 任务不同(分割);退化分解服务于分割鲁棒/泛化 |
| FreqDINO / FINet | 频域专家+超声分割 | 高频专家仅作组件、引用致敬,非卖点 |
| EMoE / MoSE | MoE 分歧→不确定性 | **不做**这条(已占) |
| MoIE / MoETTA | TTA+MoE 路由 | **不做**这条(已占) |

## 3. 支柱1:超声物理 MoE 模块

### 3.1 专家集合(6 超集,消融定数)

每个专家 = **固定物理核 + 少量可学通道**(参数少 → 轻量 + 抗过拟合;架构锚定 → 不语义崩)。每个专家配一张 **label-free 退化代理图** 用于路由弱监督。

| 专家 | 物理核思路 | 退化代理图 | 角色 |
|---|---|---|---|
| 去斑点 | 各向异性扩散 / 低通 | 局部方差 | 基本盘 |
| 边缘 | 梯度算子 | 梯度幅值 | 基本盘 |
| **声影** | 竖向亮度衰减检测 | 竖向亮度衰减图 | **novelty** |
| **后方增强** | 结构后明区检测 | 结构后明区图 | **novelty** |
| 对比度 | 局部对比/低频 | 低频能量 | 组件 |
| 高频纹理 | 小波高频带 | 小波高频带能量 | 组件(引 FreqDINO/FINet) |

> 注:第5(低频)与第6(高频)频谱互补且与去斑点(本质低通)有重叠,实现时把第6 明确定义为**小波高频纹理**专家以拉开区分。

### 3.2 路由

- **top-2** 稀疏路由,作用 = **正则化 / 逼专家特化**(不是省算力)。
- **空间自适应**,逐 position(x3=16×16、x4=8×8,在图像空间本就粗,够用)。
- 路由器**显式吃退化线索**(局部方差/梯度/频带能量)作为输入 → 可解释、可出热图。
- **实现 = dense 算全部 6 个专家 + per-position top-2 掩码组合**(图太小,真稀疏 dispatch 的 gather/scatter 开销大于收益,且卷积专家需邻域无法逐像素稀疏)。

### 3.3 放置

- MoE **只放 x3 / x4** 两个语义层(对应现 `feature_processor_3` / `feature_processor_4`)。
- **x2 退回普通融合**(现 `feature_processor_2`),避免 CNN 多层 MoE 方差大(文献 2604.13761 教训)。

### 3.4 激活专家数 / 利用率监控

- 逐 position 激活数恒 = k = 2(自检)。
- 整图激活专家数 ∈ [2,6]:`(mask.sum(dim=(2,3))>0).sum(dim=1)`。
- 每专家负载 `f[e] = mask.mean(dim=(0,2,3))`;`f[e]→0` = 专家死、独大 = 失衡。
- **有效专家数(报论文/消融)**:`eff_experts = exp(entropy(mean gate))`,∈[1,6],→1 即塌成单专家,健康 2~4。训练时打点早发现路由崩溃。

## 4. 支柱2:可微超声物理退化模拟器

- 可微,建模超声 image formation:**对数压缩、斑点(Rayleigh / K 分布)、深度衰减、声影、后方回声增强**。
- **三用**:
  1. **数据增强** —— 在线合成可控退化,直接缓解 BUSI(~600)小数据过拟合,把劣势转为设计优势。
  2. **路由监督** —— 合成时已知退化类型/强度,提供**物理 ground-truth 退化图**,把路由弱监督升级为物理监督。
  3. **可控实验** —— 调退化强度,实证路由器随退化正确响应(novelty 可视化)。
- **风险**:sim-to-real gap。写不准反而引入伪影。
- **硬 gate(已拍板)**:支柱2 正式纳入前,**先把模拟器作为独立模块验证保真度**——单独跑通、产出合成退化样例,判据(与真实超声的分布距离 / 下游 Dice 增益)达标后,模拟器才升级为正式第二支柱;不达标则降级为普通增强或弃用,核心论文仍由支柱1 撑住。即实现顺序上**支柱1 不依赖支柱2**,二者解耦。

## 5. 轻量(FLOPs / 推理速度优先)

- "轻量"靠**架构**拿,不靠稀疏 dispatch:PVT-B0 轻骨干(现成) + 锚定小专家(固定核+少通道,channel=32) + MoE 只占两小层。
- 论文报**全模型 FLOPs / FPS**,对标 ~85.9% 的重型 NAS 多分支 SOTA;卖点 = 跨域泛化 + 可解释 + 轻量,而非单点刷 Dice。

## 6. Loss(接入已实现钩子)

接进 `models/Hybrid/USEANet/__init__.py` 适配器的 `deep_supervision_loss` 方法(`main.py` 已有 `hasattr(model,'deep_supervision_loss')` 钩子):

- **主**:USEANet 原生加权 structure_loss(深监督,前景 + 0.8×背景)。
- **辅1 路由监督**:router 权重对齐退化代理图 / 物理 GT 退化图。默认**小权重 + 线性退火**(给路由器锚定但留学习空间);强度做消融。
- **辅2 load-balance / switch loss**:防专家失衡。

## 7. 实验

- **超声主线**:busi / bus / BUSBRA / tuscui。
- **跨模态加分**:U-Bench 多模态(息肉/细胞核/心脏等),证明框架可迁移。
- **可视化**:路由 ↔ 退化区域对应热图;模拟器合成退化样例。
- **消融**:专家数 2/4/6 · top-k 1 vs 2 · load-balance(entropy/importance/switch) · MoE 放置层 · 物理先验路由 vs 通用路由 · 路由监督强度 · **有无模拟器** · 专家利用率(eff_experts)。

## 9. 风险清单

1. **小数据过拟合 / 路由崩溃**(头号)→ 锚定小专家 + top-2 软稀疏 + 路由监督 + load-balance + eff_experts 监控 + 模拟器增强。
2. **模拟器 sim-to-real gap** → 前置保真度验证 gate。
3. **单数据集 Dice 未必超 85% NAS SOTA** → 卖点放泛化+可解释+轻量。
4. **跨模态加分被 reviewer 当主张攻击** → 明确写成"次要结果/框架可迁移性",不与核心 novelty 混。
5. **投稿前需复扫 arXiv** `ultrasound mixture of experts segmentation` 防 2026 H2 并行撞车。

## 10. 决策记录(2026-06-14 拍板)

- **模拟器**:先作为**独立模块单独验证保真度**(硬 gate,见 §4),通过后才正式当支柱2;支柱1 与之解耦,不依赖它。
- **专家数**:第一版**直接上全 6 专家**(去斑点+边缘+声影+后方增强+对比度+高频纹理);专家数 2/4/6 仍作消融,但实现以 6 为起点。
- **跨模态加分定位措辞(定稿)**:**不主张** SOTA 跨模态泛化(避开 cross-modality DG / 模态专家那批正面战场);仅作为"**为超声设计的退化感知框架迁移到其他模态时不退化、仍具竞争力**"的**框架可迁移性证据**,与核心超声 novelty **解耦汇报**(独立小节,不写进主张句)。
